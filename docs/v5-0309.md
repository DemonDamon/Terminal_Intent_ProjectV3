# v0.5.2 技术方案：交付阶段数据集划分 + 统一预测管道

## 1. 版本变更概述

### 数据策略变更
| 维度 | v0.5.1 (开发阶段) | v0.5.2 (交付阶段) |
|------|-------------------|-------------------|
| 训练数据 | 8月 | 8+9月全量 |
| 验证数据 | 9月 (时间切分) | 80/20 随机分层切分 |
| 切分方式 | `last_action_date` 时间点 | `train_test_split(stratify=target)` |

**变更理由**：交付阶段需要最大化训练数据利用率。80/20 随机切分保证训练集和验证集标签分布一致，阈值搜索结果更稳定。

### 管道合并
- 删除 `predict_pipline_backtest.py` — 功能合并入 `predict_pipline.py`
- 删除 `data_extra_backtest.py` — 用户名单过滤逻辑合并入 `predict_common.py`

## 2. 阈值策略

```
训练集(80%) → LightGBM 训练 → 验证集(20%) → E8 阈值搜索 → best_threshold
```

- 阈值在 **同一次训练的验证集** 上搜索，与模型严格匹配
- 阈值绑定在模型对象 `model_obj.best_threshold` 内，predict 时自动加载
- 阈值搜索算法 (E8) 和 sample_weight (E11) 逻辑不变

## 3. 统一预测管道设计

### 入口
```bash
# 全量预测
python predict_pipline.py

# 名单回测
python predict_pipline.py --user-list data/raw/user_list.csv
```

### `--user-list` 参数机制
- 无参数 → 全量预测，输出到 `marketing_list.csv`
- 有参数 → 名单回测，输出到 `marketing_list_backtest.csv`

### 用户名单过滤 (`filter_by_user_list`)
- 在**原始数据阶段**过滤（FE 之前），减少后续计算量
- 智能分隔符检测：自动识别 `|` 和 `,`
- 智能列名检测：优先 `号码` → `user_id` → 第一列
- 输出匹配统计：名单总数 / 实际匹配用户数 / 保留事件行数

## 4. 数据流图

### train_pipline.py
```
train_data_89.csv
  → DataLoader.load_and_clean()
  → UnifiedFeatureEngineer.execute()
  → train_test_split(80/20, stratify=target)
  → LightGBM auto_train (E11 sample_weight, E12 n_trials=30)
  → 验证集评估 + E8 阈值搜索
  → 保存 models/intent_v2.pkl + feature_names.pkl
```

### predict_pipline.py (全量预测)
```
predict_data_10.csv
  → load_raw_data()
  → run_feature_engineering()
  → align_features() + run_model_predict()
  → save_predictions() (含规则层标签)
  → analyze_performance()
    → 有 target: AUC/KS/P/R/F1 + 混淆矩阵 + Top-N + 用户分层
    → 无 target: 预测分布 + 用户分层
```

### predict_pipline.py --user-list (名单回测)
```
predict_data_10.csv
  → load_raw_data()
  → filter_by_user_list()  ← 在 FE 之前过滤
  → run_feature_engineering()
  → align_features() + run_model_predict()
  → save_predictions()
  → analyze_performance() (同上)
```

## 5. 输出格式说明

### 营销名单 CSV
| 列名 | 含义 |
|------|------|
| user_id | 用户ID |
| intent_label | 1=高意向, 2=低意向 |
| intent_probability | 模型概率 |
| certainty_tag | 规则层标签 (高确定性/较高确定性/有购买动作/纯意向) |

### 分析报告输出
1. **模型指标** (有 target 时)：AUC、KS、Precision、Recall、F1
2. **混淆矩阵**：TP/FP/FN/TN + 合计
3. **Top-N 截断效果**：Top 100/500/1000/5000 命中率和提升度
4. **用户分层**：
   - 按概率区间：[0,0.1) / [0.1,0.3) / [0.3,0.5) / [0.5,0.7) / [0.7,1.0]
   - 按 certainty_tag：各标签下用户数、正样本数、转化率
