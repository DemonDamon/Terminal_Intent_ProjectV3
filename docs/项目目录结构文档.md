# Terminal_Intent_ProjectV3 项目目录结构文档

## 项目概述

Terminal_Intent_ProjectV3 是一个终端意图识别项目，包含完整的机器学习 pipeline，从数据收集、特征工程、模型训练到 API 部署的全流程。
